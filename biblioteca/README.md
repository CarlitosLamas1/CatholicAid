# Biblioteca de vídeos (Veo)

Aquí guardamos los clips que generas con **Veo** (incluido en tu Gemini PRO, desde la app de Gemini o desde Flow). El proceso diario elige solo el clip que mejor encaja con cada escena del Evangelio. Si para una escena no hay clip, usa un cuadro de James Tissot.

## Cómo generar un clip
1. Abre la app de Gemini (o labs.google/flow) y elige **Vídeo / Veo**.
2. Si te deja elegir formato, marca **vertical 9:16**. Si sale horizontal, también vale: el proceso lo encaja.
3. Copia **el prompt entero** del clip que quieras (más abajo) y genéralo.
4. Si no te convence, vuelve a generarlo. Fíjate en que Jesús se parezca entre clips: pelo castaño oscuro ondulado, barba corta, túnica crema y manto terracota.
5. Descarga el vídeo y **renómbralo con su código**, por ejemplo `G08.mp4`.

## Cómo subirlo a GitHub
1. Entra en https://github.com/CarlitosLamas1/CatholicAid/tree/main/biblioteca/clips
2. Pulsa **Add file → Upload files**, arrastra el vídeo (o varios) y pulsa **Commit changes**.
3. Ya está. Al día siguiente el proceso lo usará cuando encaje.

**Clips para un día concreto** (opcional): en `biblioteca/dias/`, con el nombre `AAAA-MM-DD_eN.mp4` (N = número de escena, por ejemplo `2026-11-08_e1.mp4`). Tienen prioridad sobre la biblioteca. Pídele al gestor los prompts de un día concreto.

También valen **imágenes** (`G08.png` o `.jpg`) generadas con Gemini: se animan con un zoom lento.
