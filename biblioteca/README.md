# Biblioteca de imágenes y vídeos

Aquí guardamos las **imágenes y los clips** que generas con Gemini (incluido en tu PRO). Cada día, el proceso elige solo el que mejor encaja con cada escena del Evangelio, y **cambia de imagen como mucho cada 16 segundos**.

**Estilo:** pintura devocional, como tus ejemplos.
- **Óleo luminoso:** pinceladas visibles, luz dorada divina, rojos, crema y azules cálidos.
- **Acuarela suave:** cielos pastel, praderas de flores.

Siempre **vertical 9:16**, tierno e íntimo, que llene el corazón de bondad y amor.

> ⚠️ No subas imágenes de otros artistas sacadas de internet, aunque te gusten: tienen derechos. Úsalas solo como inspiración y genera las tuyas con Gemini.

## Orden recomendado
1. **Retratos de `personajes/`** (Jesús y María primero).
2. **Imágenes devocionales D01–D10.** Son las que más se usan: rellenan cualquier escena larga o sin imagen propia.
3. **Escenas G01–G27**, empezando por las de esta semana: G08, G25, G07 (Lc 15) · G26, G06 (Lc 16) · G12 (Mt 25) · G14, G13 (Jn 2) · G27, G16 (Lc 17).

Para cada una, mejor **imagen**: la app de Gemini deja hacer muchas al día. Los **vídeos de Veo** son pocos al día; resérvalos para las favoritas.

## Pasos
1. Si aparece Jesús (o María), **adjunta su retrato** de `personajes/` y empieza el prompt con:
   `Use the attached image as the exact reference for this character's face, hair and clothing.`
2. Copia el prompt y genera. Repite hasta que te emocione.
3. Renombra el archivo con su código: `D01.png` o `G08.png` (o `.mp4` si es vídeo).
4. Súbelo a https://github.com/CarlitosLamas1/CatholicAid/tree/main/biblioteca/clips con **Add file → Upload files → Commit changes**.

**Para un día concreto** (opcional): súbelo a `biblioteca/dias/` con el nombre `AAAA-MM-DD_eN` (por ejemplo `2026-11-08_e1.png`).
